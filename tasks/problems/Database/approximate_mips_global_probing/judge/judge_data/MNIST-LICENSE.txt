This benchmark uses all 60,000 training images, flattens 28x28 grayscale pixels
to 784 float32 values without normalization, and applies a fixed permutation.
The image-derived matrix and exact-inner-product query truth are supplied under
CC BY-SA 3.0. Labels and the 10,000-image classification test set are not used.
See mnist-provenance.json for source/derived hashes and sampling details.
