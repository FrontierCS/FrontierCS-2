- `refuted_pairs`: Per development workload, in suite order: 1 if the case was validated as
  refuted, else 0.
- `wall_time_seconds`: Per development workload, in suite order: the measured search time in
  seconds; a failed case is charged its budget.
- `search_iterations`: Per development workload, in suite order: the search's own reported
  iteration count.
- `backtracks`: Per development workload, in suite order: the search's own reported backtrack
  count.
