- `e2e_latency_seconds`: Candidate latency per train workload, in seconds. Each metric list is
  sorted independently; positions match neither other metrics nor workloads.
- `psnr_db`: Candidate PSNR per train workload, in dB, sorted; an exact match is reported as
  "positive_infinity".
- `ssim`: Candidate SSIM per train workload, sorted.
- `lpips`: Candidate LPIPS per train workload, sorted.
